# 10MinTalk

**10MinTalk** is a real-time private chat platform that allows users to create temporary chat rooms for quick conversations.
Rooms automatically expire after a short time, ensuring conversations stay private and temporary.

---

## Technologies Used

* Next.js
* TypeScript
* Redis
* Elysia
* Tailwind CSS
* Upstash Realtime (WebSocket-based messaging)

---

## Features

* Create private chat rooms instantly
* Unique room tokens for secure access
* Real-time messaging with low latency
* Automatic room expiration using Redis TTL
* Temporary conversations with no permanent storage
* Error handling for invalid or expired rooms
* Clean and responsive UI
